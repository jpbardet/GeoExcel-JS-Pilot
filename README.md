# GeoExcel JavaScript pilot 0.1.0

Excel formula: `=GEOXL.GEOEXCEL_VERSION()`

Expected return: `GeoExcel JS 0.1.0`

The JavaScript function is named `GeoExcel_Version`. Office custom functions add
the manifest namespace `GEOXL` to the worksheet formula. No LAMBDA or VBA is used.

## Publish on GitHub Pages

1. Create a GitHub repository for the pilot (a public repository is simplest for
   GitHub Pages availability; repository plan/settings govern private support).
2. Upload the files INSIDE this folder to the repository root. Keep their names.
   Include the three PNG icons, runtime HTML, metadata and manifest template.
3. In repository Settings > Pages, choose Deploy from a branch, select your
   branch (usually main) and /(root), then Save.
4. Wait for GitHub Pages deployment to complete. Open the Pages URL displayed
   in Settings > Pages. Do not use a raw.githubusercontent.com file URL.
5. On the hosted page, click Download GeoExcel manifest. It generates the final
   manifest with the correct Pages URL automatically; no URL editing is needed.
6. Follow the hosted Mac instructions to load the manifest. Use a blank workbook
   and test the formula above. Excel for the web has upload instructions too.

No local server, Node.js, or certificate installation is required to run this
hosted pilot. Do not try importing manifest.template.xml: use the downloaded
GeoExcel-manifest.xml generated by the hosted page.

## Scope

The library returns its own JS pilot version, independent of the existing LAMBDA
library version. It does not read that library's version from a workbook.
No workbook values are read/written by our function. The manifest declares
ReadWriteDocument for Excel custom functions. No account system or analytics
is implemented. Microsoft Office.js loads from its HTTPS CDN.

The same static files support Mac, Windows and browser runtimes with compatible
Excel versions. This pilot documents Mac sideloading and browser uploading;
Windows desktop registration is a separate setup step, not supplied as an
automatic installer. Account policies can restrict custom add-ins.

GitHub Pages hosts the files, while Excel executes the function. Hosting is not
automatic installation. Reloading or Office cache clearing can be necessary
after changes; keep function IDs and manifest ID stable.

The setup page verifies files can be fetched and XML can be parsed. It does NOT
perform Office schema certification or prove Excel successfully loaded the add-in.
Only receiving the expected value in Excel completes the end-to-end test.
