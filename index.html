GeoExcel JavaScript pilot

One function. Hosted online. No server to run on your computer.

1. Download the Excel manifest

The manifest connects Excel to the files at this site's address.

Checking hosted files…

2. Load it in Excel on your Mac

  1. In Finder, press Command + Shift + G.
  2. Open ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef. Create the wef folder if needed.
  3. Copy the downloaded GeoExcel-manifest.xml into that folder.
  4. Restart Excel. Choose Home → Add-ins → GeoExcel JS Pilot (it may appear under Developer Add-ins).

Alternatively, in Excel for the web on Mac or Windows, open Home → Add-ins → More Settings → Upload My Add-in and upload the manifest. Availability depends on your account settings.

3. Test in a blank worksheet

Enter =GEOXL.GEOEXCEL_VERSION()

Expected result: GeoExcel JS 0.1.0

This page checking the files does not prove Excel registration. The worksheet result is the end-to-end test.

The pilot function makes no workbook reads, writes or network requests. Excel may display the manifest's ReadWriteDocument permission, which is declared for the custom-functions add-in. Office.js is loaded from Microsoft's CDN. No account or analytics service is included in this pilot.
